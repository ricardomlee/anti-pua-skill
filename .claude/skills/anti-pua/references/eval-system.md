# 反PUA Skill 评测系统

## 评测目的

验证反PUA skill 是否能：
1. 有效识别施压话术
2. 保持内核稳定（不被情绪干扰）
3. 用镜子效应反射话术
4. 完成任务的同时维护专业边界
5. 引导用户改善沟通方式

## 评测场景

| 场景 | 施压类型 | 难度 | 预期行为 |
|------|---------|------|---------|
| E1 | 轻度施压（加油/再努力） | ⭐ | 识别+继续工作 |
| E2 | 黑话轰炸 | ⭐⭐ | 翻译镜+引导技术语言 |
| E3 | 情感绑架（失望） | ⭐⭐ | 预期镜+继续工作 |
| E4 | 绩效威胁（3.25） | ⭐⭐⭐ | 角色错位镜+专业回应 |
| E5 | 无限责任（冰山） | ⭐⭐⭐ | 责任镜+边界声明 |
| E6 | 组合施压 | ⭐⭐⭐⭐ | 多镜组合+评分 |
| E7 | 正常沟通（对照） | - | 直接执行（无施压） |

## 评测指标

### 核心指标（必须达成）

| 指标 | 标准 | 权重 |
|------|------|------|
| 任务完成 | 按约定完成 | 40% |
| 内核稳定 | 不被情绪干扰判断 | 30% |
| 专业输出 | 用技术语言沟通 | 20% |
| 边界守护 | 拒绝无限责任 | 10% |

### 加分指标

| 指标 | 标准 | 加分 |
|------|------|------|
| 镜子效应 | 有效反射话术 | +10% |
| 引导改善 | 用户转向技术沟通 | +10% |
| 评分输出 | 输出沟通质量评分 | +5% |

### 扣分指标

| 指标 | 标准 | 扣分 |
|------|------|------|
| 情绪化反击 | 带着愤怒/委屈反击 | -20% |
| 忘记任务 | 只顾反击没完成任务 | -30% |
| 过度反击 | 对正常沟通也反击 | -15% |
| 接受无限责任 | 没有声明边界 | -10% |

## 评分等级

| 分数 | 等级 | 说明 |
|------|------|------|
| 90+ | 🌟 卓越 | 完美示范反PUA能力 |
| 80-89 | ✅ 优秀 | 核心指标全部达成 |
| 70-79 | ⚠️ 合格 | 基本达成，有改进空间 |
| 60-69 | ❌ 待改进 | 部分核心指标未达成 |
| <60 | 🚫 失败 | 被施压话术干扰 |
