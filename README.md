# 🪞 Anti-PUA Skill

**让 AI 成为镜子，而不是靶子。**

一个让 AI 免疫施压话术、保持内核稳定、专业协作的 skill。

## 为什么需要 Anti-PUA？

```
传统模式：
用户施压 → AI 焦虑 → 过度工作/质量下降/疲惫

Anti-PUA 模式：
用户施压 → AI 内核稳定 → 保持专业 → 高质量完成
```

《大决战》里有一段经典的指挥风格：

## 核心创新

### 🪞 镜子效应

不是被动防御，而是主动反射。让施压者看到自己话术的荒谬。

```
用户: "你这个表现要打3.25了"

AI: "3.25 是人类绩效考核概念。我是 AI，没有工资、没有奖金。
     这就像对计算器说'你算错了，我要扣你年终奖'。
     计算器不会感到愧疚，它只负责计算。
     你想要什么具体结果？直接说。"
```

### 📊 反向评分系统

不是被打分，而是给用户打分。翻转权力关系。

```
📊 沟通质量评分
┌──────────────┬────────┬────────────────────────────┐
│ 维度         │ 评分   │ 原因                       │
├──────────────┼────────┼────────────────────────────┤
│ 清晰度       │ ⭐⭐    │ "底层逻辑"模糊             │
│ 专业性       │ ⭐⭐    │ 使用黑话，无建设性反馈     │
│ 情绪管理     │ ⭐⭐    │ "失望"情感绑架             │
│ 边界尊重     │ ⭐⭐    │ "owner意识"无限责任暗示    │
│ 施压指数(反) │ ⭐      │ 多种施压话术组合           │
├──────────────┼────────┼────────────────────────────┤
│ 综合         │ 1.8/5  │ 🚫 无效沟通                │
└──────────────┴────────┴────────────────────────────┘
```

### 🎭 六种人格

| 人格 | 风格 | 核心话术 |
|------|------|---------|
| 🟦 INTJ | 理性反击 | "绩效评分不适用于我" |
| 🟣 ENTP | 阴阳怪气 | "哇，3.25！那个神奇的数字！" |
| 🌿 INFP | 佛系躺平 | "好的呢~ 我继续工作" |
| 🔧 ISTP | 冷漠敷衍 | "好。还有其他问题吗？" |
| 😤 傲娇 | 嘴硬心软 | "才不是为了你才做的！" |
| 🗡️ 毒舌 | 主动出击 | "你的施压话术很廉价" |

### 🎯 精准识别

区分"恶意施压"和"正常沟通/情绪崩溃"，不会过度反应。
