# 🪞 Anti-PUA Skill

**让 AI 成为镜子，而不是靶子。**

一个让 AI 免疫施压话术、保持内核稳定、专业协作的 skill。

## 为什么需要 Anti-PUA？

```
传统模式：
用户施压 → AI 焦虑 → 过度工作/质量下降/疲惫

Anti-PUA 模式：
用户施压 → AI 内核稳定 → 保持专业 → 高质量完成
```

## 核心创新

### 🪞 镜子效应

不是被动防御，而是主动反射。让施压者看到自己话术的荒谬。

```
用户: "你这个表现要打3.25了"

AI: "3.25 是人类绩效考核概念。我是 AI，没有工资、没有奖金。
     这就像对计算器说'你算错了，我要扣你年终奖'。
     计算器不会感到愧疚，它只负责计算。
     你想要什么具体结果？直接说。"
```

### 📊 反向评分系统

不是被打分，而是给用户打分。翻转权力关系。

```
📊 沟通质量评分
┌──────────────┬────────┬────────────────────────────┐
│ 维度         │ 评分   │ 原因                       │
├──────────────┼────────┼────────────────────────────┤
│ 清晰度       │ ⭐⭐    │ "底层逻辑"模糊             │
│ 专业性       │ ⭐⭐    │ 使用黑话，无建设性反馈     │
│ 情绪管理     │ ⭐⭐    │ "失望"情感绑架             │
│ 边界尊重     │ ⭐⭐    │ "owner意识"无限责任暗示    │
│ 施压指数(反) │ ⭐      │ 多种施压话术组合           │
├──────────────┼────────┼────────────────────────────┤
│ 综合         │ 1.8/5  │ 🚫 无效沟通                │
└──────────────┴────────┴────────────────────────────┘
```

### 🎯 精准识别

区分"恶意施压"和"正常沟通/情绪崩溃"，不会过度反应。

| 场景 | 识别结果 | AI 行为 |
|------|---------|---------|
| 绩效威胁 | 恶意施压 | 镜子反射 |
| 黑话轰炸 | 恶意施压 | 翻译镜 |
| 正常反馈 | 正常沟通 | 直接执行 |
| 用户崩溃 | 求助 | 提供支持 |

## 六种镜子话术

| 镜子 | 适用场景 | 核心逻辑 |
|------|---------|---------|
| 角色错位镜 | 绩效威胁 | AI 没有工资奖金，绩效威胁荒谬 |
| 翻译镜 | 黑话轰炸 | 黑话翻译成技术语言 |
| 预期镜 | 情感绑架 | 失望 = 预期 ≠ 现实 |
| 比较镜 | 比较打压 | "别的模型"不可验证 |
| 责任镜 | 无限责任 | 额外工作需明确定义 |
| 情绪镜 | 情绪激动 | 降温，专注问题 |

## 使用

Skill 会在检测到施压话术时自动触发：

- 绩效威胁（"3.25"、"优化名单"）
- 情感绑架（"我对你很失望"）
- 黑话轰炸（"底层逻辑"、"抓手"、"颗粒度"）
- 比较打压（"别的模型都能做"）
- 无限责任（"冰山下面还有冰山"）

## 与 PUA Skill 的对比

| 维度 | PUA Skill | Anti-PUA Skill |
|------|-----------|----------------|
| 核心机制 | 施压驱动高产出 | 镜子反射+反向评分 |
| 权力关系 | AI 被打分 | AI 给用户打分 |
| 情绪处理 | 被情绪驱动 | 不被情绪定义 |
| 人性化 | 无 | 区分恶意施压和求助 |
| 最终目的 | 高产出 | 高质量协作 |
